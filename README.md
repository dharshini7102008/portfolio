 
# Dharshini - Developer Portfolio

## About the Project
This is my personal developer portfolio website, created using HTML and CSS. It showcases my introduction, projects, and contact information.

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Design
- Media Queries
- Git and GitHub

## Features
- Semantic HTML structure
- Responsive navigation bar
- About Me section
- Projects displayed using CSS Grid
- Contact section with email and GitHub links
- Mobile-friendly design
- Dark theme with purple accents

## Project Structure

portfolio/
│
├── index.html
├── style.css
└── README.md

## How to Run Locally
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your web browser.
